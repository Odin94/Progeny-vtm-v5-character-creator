# Security maintenance — 22 October 2026

## Runtime

Production APIs previously ran Node.js 24.20.0. Node.js 24.22.1 fixes the October 21 security release, including CVE-2026-111497 (Brotli decoder out-of-bounds write / remote code execution), DNS and TLS validation issues, and bundled dependency vulnerabilities. Require the patched Node 24 LTS line in package engines and pin development/build selection with `.nvmrc`.

Official advisory: https://nodejs.org/en/blog/vulnerability/october-2026-security-releases

## Dependencies

Update affected direct dependencies and constrain vulnerable transitive versions to compatible patched releases. Preserve pnpm's existing minimum release age policy. Overrides are scoped to the existing major version where dependency trees require more than one major.

Both backend and frontend `pnpm audit --json` reports have zero known vulnerabilities.

## Verification

Builds and automated tests run with the official Node.js 24.22.1 binary, checked against the published SHA-256 checksum. Backend builds/tests and frontend production builds pass. Frontend TypeScript checking and all 632 frontend / 89 backend tests pass. Frontend bundle verification uses `pnpm exec vite build`; source-map uploads are handled by the production deployment.
